Windows Forms Application – F#
 Overview

This project is a Windows Forms desktop application developed using F# and .NET.
It demonstrates how functional programming concepts can be applied in a Windows Forms (WinForms) environment while maintaining a clean and layered architecture.

The application provides a responsive user interface and separates UI logic from business logic and data access for better maintainability and scalability.

Features

User-friendly Windows Forms interface

Functional programming with F#

Clear separation between UI and business logic

Modular and reusable code

Error handling and validation
